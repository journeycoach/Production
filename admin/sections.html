How Page Sections Work Each page of your site is divided into named sections (Hero, About, Testimonials, etc.). Here you can: show or hide any section without deleting content, drag to reorder sections within a page, set a section to Draft so it's hidden on the live site until you're ready, and add admin notes to remind yourself what a section is for. Changes take effect immediately when saved.
