## Writing partner: repetition checks and idea-to-post drafting

- Added authenticated `/api/admin/writing-assistant`, separate from storage/publishing. GET reports configuration status only. POST supports semantic repetition checking and LinkedIn/blog draft development. No action automatically saves or publishes.
- Repetition uses OpenAI embeddings (content hash cache in process) across published posts, confirmed-use snapshots and other ideas' saved draft versions. It excludes the current idea's unsent revisions, merges exact duplicate text while retaining all source labels, retrieves closest passages, and asks an editorial model to assess insight/problem/example/challenge with up to three comparisons and fresh angles. Source metadata comes from database records, not model output; quotations are checked against source passages. Coverage counts and missing-history limitations are shown explicitly. Libraries beyond 400 passages receive an explicit index-needed error rather than an incomplete search.
- “Turn this into a post” accepts LinkedIn or blog, optional direction, saved idea notes and current unsaved draft. The generated suggestion is editable, with review notes. “Use this draft” fills the existing editor as a new version, clears review checks and preserves earlier saved versions. User then saves and publishes manually through existing flow. Source references, raw imports and private review notes are omitted from generation input.
- Configuration required: server-only `OPENAI_API_KEY`. Optional `OPENAI_WRITING_MODEL` (default gpt-4.1-mini) and `OPENAI_EMBEDDING_MODEL` (default text-embedding-3-small). Keep credentials in ignored .env.local locally and deployment environment variables in Vercel, never browser code. Restart local server after setting the key. ChatGPT subscription does not configure API billing. OpenAI Responses requests use store:false. Needed text is sent to OpenAI only on user-triggered actions. Private route is auth-protected and private/no-store; provider error bodies and draft text are never logged.
